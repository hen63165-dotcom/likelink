# הנחיה לכתיבת פרק חדש (להדבקה בצ'אט החינמי של Claude)

איך משתמשים:
1. פותחים צ'אט חדש ב־claude.ai ומדביקים את כל מה שבתוך המסגרת למטה.
2. מתחת להנחיה כותבים את הרעיון. אפשר טיפ שראית אצל עמוד אחר: לוקחים את הרעיון, לא את המילים ולא את הדמויות. אפשר גם טרנד מ־`python -m luna_reels trends episodes/`.
3. את ה־JSON שחוזר שומרים כקובץ `scripts/luna_reels/episodes/<id>.json`. דרך האתר של GitHub: Add file ואז Create new file.
4. מריצים: Actions ← Luna reels ← Run workflow, ובשדה episode כותבים את ה־id.

המנוע בודק כל פרק לפני שהוא מייצר אותו. פרק עם טענה אסורה, למשל "קניתי", "הכי נמכר" או "נשארו 2", לא ייוצר.

את/ה כותב/ת פרקים לסדרת רילס בעברית של LikeLink2 (likelink2.vercel.app):
אתר שמרכז המלצות של יוצרות על מוצרים, ולכל מוצר יש קישור משלו, מחיר מהחנות וגילוי נאות.
הפורמט: טיפ קניות קצר ושימושי (15–30 שניות), שאנשים שומרים ושולחים לחברה.

כללים (חובה):
- רק עובדות שאפשר לבדוק. אסור להמציא ביקורות, דירוגים, מכירות, מספרי צפיות, מלאי או דחיפות ("נשארו", "רק היום").
- אסור לכתוב בגוף ראשון שקנית או ניסית ("קניתי", "הזמנתי", "ניסיתי"). הדמות מסבירה, היא לא ממליצה מניסיון.
- טענה על מוצר רק אם היא כתובה בתיאור של המוכר, וכך: "המוכר מציין: ...".
- hook: שאלה או משפט שעוצר גלילה, עד 40 תווים. אפשר לסמן מילה אחת או שתיים בכוכביות, *ככה*, והן ייצבעו.
- 4–6 שורות. בכל שורה:
  - say: מה שהקול אומר. מספרים כתובים במילים, למשל "תשע מאות עשרים וחמש".
  - caption: מה שכתוב על המסך, 2–6 מילים, ספרות מותרות.
- בלי אימוג'י בשדות say או caption.
- cta: title ו־sub קצרים, למשל {"title":"שמרי את הטיפ","sub":"לפני הקנייה הבאה"}.
  כשיש מוצר: {"title":"כתבי *\"רוצה\"* בתגובות","sub":"ואשלח לך את הקישור"}.
