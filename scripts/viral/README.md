# ריל ויראלי: מתסריט עד אינסטגרם, בקליק אחד

`viral_reel.py` יוצר ריל אנכי בעברית, באורך 25–30 שניות, ל־LikeLink2, ומפרסם אותו באינסטגרם רילס. לא צריך לגעת בשום דבר באמצע.

| שלב | מה קורה |
|---|---|
| תסריט | אחד משלושה תסריטים (מתחלף כל יום, או לפי בחירה). כל אחד נפתח בהוק של 2.5 שניות ואומר רק מה שהאתר עושה היום, בלי מספרים מומצאים ובלי המלצות מזויפות. |
| קול | ElevenLabs מקריא את כל התסריט בטייק אחד, כדי שהקול יישמע טבעי, ומחזיר את הזמן של כל מילה. |
| וידאו | Replicate יוצר 3 קליפים אנכיים ביחס 9:16, לפי סצנות שנכתבו לתסריט. |
| עריכה | MoviePy מחבר את הקליפים לקול. הוא מוסיף זום חד בזמן ההוק, כתוביות גדולות מילה אחרי מילה במרכז המסך (מילות מפתח בצהוב), תווית "נוצר בבינה מלאכותית" ומסך סיום. הפלט הוא 1080×1920 עם סאונד. |
| מוזיקה | רק שיר שתבחרי (`MUSIC_PATH`), בעוצמה נמוכה. בלי שיר אין מוזיקה, אף פעם לא שיר אקראי. |
| אינסטגרם | מעלה את הקובץ, מחכה שאינסטגרם יסיים לעבד אותו, מפרסם, ואז מאמת עם מזהה הפוסט והקישור שאינסטגרם מחזיר. הפוסט נחשב מפורסם רק אחרי האימות הזה. |

לפני הפרסום הסקריפט בודק שהאתר והנתונים שלו עונים. אם האתר למטה, הוא לא יפרסם ריל ששולח אנשים לאתר ריק.

## מה לחבר (פעם אחת)

ב־GitHub: **Settings → Secrets and variables → Actions → New repository secret**

| שם | מאיפה לוקחים |
|---|---|
| `ELEVENLABS_API_KEY` | ב־elevenlabs.io: Profile ואז API Keys |
| `ELEVENLABS_VOICE_ID` (רשות) | ב־ElevenLabs: Voices ואז Voice Library. מסננים לעברית, בוחרים קול ומעתיקים את ה־Voice ID |
| `REPLICATE_API_TOKEN` | ב־replicate.com: Account ואז API tokens |
| `IG_ACCESS_TOKEN` | טוקן ארוך־טווח של Meta עם ההרשאות `instagram_basic`, `instagram_content_publish` ו־`pages_read_engagement` |
| `IG_USER_ID` | המזהה של חשבון האינסטגרם העסקי (Business או Creator, מחובר לדף פייסבוק) |

המפתחות אף פעם לא נכנסים לקוד או לצ׳אט, רק ל־Secrets.

## כמה זה עולה

- **אינסטגרם:** חינם.
- **ElevenLabs:** בתוכנית החינמית יש מעט קרדיטים בחודש, אבל היא לא מתירה שימוש מסחרי ומחייבת קרדיט ל־ElevenLabs. לשיווק האתר צריך תוכנית בתשלום (Starter עולה כמה דולרים בחודש).
- **Replicate:** משלמים לפי כל סרטון שנוצר, וצריך להוסיף כרטיס אשראי. בכל ריל יש 3 קליפים. המודל שמוגדר כברירת מחדל הוא `wan-video/wan-2.2-t2v-fast`; את המחיר העדכני רואים בעמוד שלו ב־Replicate.

## איך מריצים (קליק אחד)

1. ב־GitHub: **Actions → Viral reel → Run workflow**.
2. בשדה `post`: ‏`yes` מפרסם באינסטגרם, ‏`no` רק מייצר את הסרטון כדי שתראי אותו קודם.
3. בסיום, הסרטון והקובץ `viral_reel_result.json` מצורפים להרצה תחת **Artifacts**. אחרי פרסום יש בקובץ גם את הקישור לאינסטגרם.

**הרצה במחשב:**
1. מתקינים: `pip install -r scripts/viral/requirements.txt`
2. מגדירים את המפתחות כמשתני סביבה.
3. מריצים: `python scripts/viral/viral_reel.py`

**בדיקת העריכה בלי APIs ובלי עלות:**
`python scripts/viral/viral_reel.py --offline-render-test`

**הגדרות רשות (משתני סביבה):**
- `SCRIPT_VARIANT`
- `MUSIC_PATH`, `MUSIC_VOLUME`
- `REPLICATE_VIDEO_MODEL`, `REPLICATE_VIDEO_INPUT` (JSON), `SCENES`
- `ELEVENLABS_MODEL` (ברירת המחדל `eleven_v3`, שתומך בעברית)
- `GRAPH_API_VERSION`
- `SITE_URL`
