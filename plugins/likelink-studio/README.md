# LikeLink Studio — a Claude Code plugin

LikeLink2's own skills, one command per job. Built for a Hebrew affiliate-creator site that runs on free tools and tells the truth.

| Command | What it does |
|---|---|
| `/likelink-studio:today` | the whole day: is the site healthy, what to post on Instagram/TikTok/stories, which story to render, what to log |
| `/likelink-studio:new-product` | from an affiliate link to the site and the feeds: real store data, studio photo, a character, a story, posts, checks, ship |
| `/likelink-studio:story` | a story reel in the creator-story look: a character per product, a scene per line, yellow captions, the name tag, the real product photo |
| `/likelink-studio:studio-photo` | a white or busy seller photo → a studio shot (product untouched, labelled) |
| `/likelink-studio:cast` | add or change a character: suit, hair, eyes, outfit, product; drawn free on GitHub |
| `/likelink-studio:master-check` | any reel or post against the 12 rules built on Instagram's own signals |
| `/likelink-studio:truth-guard` | the last gate: disclosure, AI labels, the seller's own claims, no other brands, no paid services, no secrets |
| `/likelink-studio:ship` | tests → PR → merge → point the live site at the new build → verify |

## Install

In Claude Code:

```
/plugin marketplace add hen63165-dotcom/likelink
/plugin install likelink-studio@likelink
```

The skills work inside a checkout of https://github.com/hen63165-dotcom/likelink.

## Rules it never breaks

Nothing is posted, sent, bought or charged without the owner. No invented numbers, no other brands, no real person's likeness, every AI character labelled, every affiliate post disclosed. No skill promises a viral result: they raise the odds and measure.
