## שלושה דברים שנפתחים רק מהחשבונות שלך

את כל הסודות (secrets) מוסיפים באותו מקום: GitHub → המאגר `likelink` → Settings → Secrets and variables → Actions → **New repository secret**. השם חייב להיות בדיוק כמו שכתוב כאן.

### 1. הענן (Supabase): חסום עכשיו

**מה קורה:** בתוכנית החינמית נגמרה מכסת התעבורה (cached egress), ולכן Supabase חסם את הפרויקט. כל קריאה לענן מחזירה 402.
האתר ממשיך לעבוד מהעותק השמור של הקטלוג. מה שלא עובד:
- הרשמה וכניסה לסטודיו;
- ספירת קליקים;
- המשימות האוטומטיות בענן (autopilot, Native reels, מנוע השיווק).

**מה לעושים (אחת משתיים):**
- **לשדרג לתוכנית Pro:** ‏supabase.com/dashboard → הארגון → Billing → Upgrade. המחיר מופיע שם (בערך 25$ לחודש). השירות חוזר בדרך כלל תוך דקות.
- **לחכות לאיפוס החודשי:** ‏Dashboard → Usage מראה מתי מתחיל מחזור החיוב הבא.

**בדיקה:** ‏Actions → Ops doctor → Run workflow. השורה `cloud :: site API` צריכה להיות `OK`.

### 2. אינסטגרם: הבוט של "רוצה"

מי שמגיב "רוצה", "לינק" או "קישור" על פוסט מוצר מקבל הודעה פרטית אחת עם הקישור למוצר והגילוי. מתחת לתגובה שלו נכתב "שלחתי לך בפרטי 📩".

1. באפליקציית אינסטגרם: הגדרות → סוג חשבון וכלים → מעבר ל**חשבון מקצועי** (Creator או Business).
2. ב-developers.facebook.com: ‏My Apps → Create App. לבחור את השימוש של אינסטגרם (ניהול הודעות ותוכן באינסטגרם).
3. באפליקציה שנוצרה: ‏Instagram → API setup with Instagram login → Generate access tokens → Add account, ולהתחבר לחשבון האינסטגרם.
4. ההרשאות שצריך לאשר:
   - `instagram_business_basic`
   - `instagram_business_manage_comments`
   - `instagram_business_manage_messages`
   - `instagram_business_content_publish` (לפרסום רילס בהמשך)
5. להעתיק את ה**טוקן** (מתחיל ב-`IG`) ואת **מספר החשבון** (Instagram user ID) שמופיע לידו.
6. להוסיף שני secrets:
   - `IG_ACCESS_TOKEN` = הטוקן
   - `IG_USER_ID` = המספר
7. **בדיקה:** ‏Actions → Instagram comment bot → Run workflow. בסיכום הריצה צריכה להופיע רשימת פוסטים, לא `REQUIRES_CONNECTION`.

**חשוב לדעת:**
- הטוקן תקף בערך 60 יום. לפני שהוא פג מייצרים חדש באותו מסך ומעדכנים את ה-secret.
- הבוט עונה רק על פוסט שהכיתוב שלו כולל את שם המוצר המדויק. הכיתוב מהדרופ היומי כבר כולל אותו.
- הבוט עונה רק לתגובות מ-7 הימים האחרונים, ועד 40 תגובות בריצה.
- אם תשובות לאנשים שאין להם תפקיד באפליקציה נכשלות, מטא דורשת להעביר את האפליקציה ל-Live, כולל בדיקת App Review להרשאות התגובות וההודעות.
- השמות בתפריטים של מטא משתנים מדי פעם. העיקר הוא Instagram login והרשאות התגובות וההודעות.

### 3. אליאקספרס: מחירים, תמונות וסרטונים אמיתיים מהחנות

היום המחירים באתר לא מוצגים, וכתוב "המחיר המעודכן בחנות". אחרי החיבור, האתר יציג את המחיר שהחנות עצמה מדווחת (בשקלים, עם משלוח לישראל), את גלריית התמונות של החנות ואת הסרטון של המוכר.

1. ב-portals.aliexpress.com: להיכנס עם חשבון השותפים, זה שממנו הקישורים באתר. ה-**Tracking ID** מופיע בחשבון.
2. ב-openservice.aliexpress.com (AliExpress Open Platform): להירשם כמפתחים וליצור אפליקציה מסוג **Affiliate API**. אחרי האישור מקבלים **App Key** ו-**App Secret**.
3. להוסיף שלושה secrets:
   - `ALIEXPRESS_APP_KEY`
   - `ALIEXPRESS_APP_SECRET`
   - `ALIEXPRESS_TRACKING_ID`
4. Actions → **Catalog sync** → Run workflow. אחרי ריצה מוצלחת הקטלוג מתעדכן והאתר מתפרסם מחדש לבד.
