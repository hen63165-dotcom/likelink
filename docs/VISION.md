# LikeLink — the vision (read this before building anything)

LikeLink is **not** another link-in-bio, store, affiliate site, search engine or reel
generator. It is one **AI-powered Creator Commerce & Discovery Network** that ties the
whole chain together:

product → link → creator → content → trust → discovery → purchase → measurement → optimisation

for three sides at once: **buyers**, **creators / influencers / marketers / sellers**
(from a first-time creator to a large brand or agency), and **the system itself**
(LikeLink + Luna).

## 1. The buyer's problem and promise

Today a buyer sees the same product in a TikTok, a reel, a story, a link in bio, a
comment, Linktree, Amazon, AliExpress, a private store, ten creators and ten prices,
and asks: *"Where should I actually buy this?"*

**Promise:** *"I tell LikeLink what I'm looking for, it does the hard work, and I choose
from the relevant, trustworthy options it found."* Not 10,000 results and not one forced
"right" answer — the best-matching candidates first, with the reason each one is there.
Search should be fast and natural (text today; image, voice and "similar products" later).

## 2. Trust layer — evidence, never invention

Ranking is built from real signals and **shown to the buyer** ("why is this here?"):
product and link source, availability, price, performance, clicks, conversions when they
exist, content quality, relevance to the search, Studio/campaign data, real ratings when
they exist, LikeLink verifications, AI-content labels, affiliate relationship.

Never invent ratings, reviews, sales or "trusted". A signal that is not in the data is
absent. Never tell anyone a result is "number 1".

## 3. Healthy competition

When 100 creators promote the same product, LikeLink gives each link a fair chance to be
judged on real data — relevance, price, availability, performance, conversions, content
quality, audience fit, source trust. Whoever brings a good product, good content, good
information and real conversions gets discovered — not whoever shouts loudest.

## 4. Creators: the Studio is their factory

A big influencer has products, brand deals, an editor and a campaign manager; a small
creator starts from zero. The Studio gives everyone (small → medium → large → marketer →
store → brand → agency) one Creator Commerce Workspace:

**find** products and opportunities → **create** content (hooks, UGC, stories, 3D
creatives, reels, CTAs, variants) → **publish** to connected channels → **measure**
clicks, views, engagement, conversions when available → **learn** what worked →
**earn** (commissions/products/campaigns per the model) → **grow** with automation.

## 5. Luna is the intelligence layer

Not a chat widget. For each product Luna works out who it is for, which hook, reel, UGC,
3D story and CTA fit, and which creative to test; after publishing it reads what really
happened and designs the next experiment: Data → Intelligence → Creative → Distribution
→ Data. Luna never invents analytics: observed data and AI recommendations are always
kept apart.

## 6. LikeLink markets itself with the same machine

LikeLink Studio → Luna → creative → legitimate distribution → measurement → optimisation
→ new users → new Studios → more products and content → more discovery → more buyers →
more data → a better system. Network effect: Buyer ↔ Creator ↔ Product ↔ LikeLink.

## 7. The link becomes a living commerce object

A link is not an address. It knows its product, its publisher, its source, its Studio,
its creative, how many people reached it, what happened, whether it is still relevant,
which content leads to it and what the buyer searched before arriving.

## 8. "Hunger", the honest kind

No fake FOMO. The pull is *"wait — what's in here?"*: products, creators, links, content,
comparisons, discoveries, evidence-based ordering, new products, trends — and the knowledge
that the system filters the noise.

## Rules for every change

1. Every public claim (site, reels, captions, ads) describes what the product does **today**.
   A vision item that is not built is never advertised as existing.
2. No income promises, no invented numbers, testimonials, reviews, rankings or "verified".
3. AI content is labelled; synthetic is never called real UGC; affiliate links are disclosed.
4. Automation runs in LikeLink's own cloud (Vercel + GitHub Actions + Supabase) with no
   dependency on paid third parties when a free, own path exists.
5. Simple for everyone: one click, organised by topic, per product — for the site's own
   catalog and for every Studio.
